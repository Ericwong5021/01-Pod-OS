# 分层记录与恢复

每次实验建立独立的私有层目录，保存以下内容：

- 层前完整目标分区镜像和候选镜像。
- 两份镜像的大小、SHA-256、对应源码提交及上游锁定。
- 修改文件清单、依赖分析和保留原因。
- 设备身份、当前槽位、目标槽位、挂载情况及分区容量。
- 写入结果、完整读回文件和哈希。
- 启动日志、功能结果、人工验收与准确的恢复目标。

任何镜像写入都应在确认目标为非当前槽、目标未挂载且备份已核对后进行。只写审核过的具体分区，写完完整读回再选择候选启动。

当前开发设备的 A 槽是 2.10.61 测试固件基线，2.30.108 原始 eMMC 备份是另一层恢复材料。二者不能混为一谈。A/B 共用 userdata，切槽不撤销应用禁用、数据迁移或应用更新。

候选失败时优先进入 Fastboot 选择已知可启动槽，或经 DA 将准确的层前镜像恢复到对应目标并完整读回。不得把候选本身当作恢复镜像。此仓库不提供通用一键刷写脚本。

RPMB、熔丝和硬件状态不属于普通 eMMC user/boot 备份保证范围。每层都必须明确“有恢复材料”和“已实测恢复”之间的差别。
